## Traceability

Do not rename or rewrite legacy IDs inside historical GitHub references, PR
titles, branch names, commit messages, test reports, evidence filenames, or
original acceptance records. When a current document needs to point to one of
those records, use the current ID and identify the legacy ID where it aids
lookup (for example, `B08.1 (legacy T08.1)`). IDs outside the mapping above are
outside this standardization scope.
