# Canonical interactive references

The downloadable handoff package includes standalone HTML exports of the approved interactive drawings. They are intentionally not committed to the application repository because `AGENTS.md` prohibits generated output. Open them in a browser and compare them directly with the application while implementing.

- `log-workout-fit.html`: use the **Import FIT** variant.
- `activity-review-timeline.html`: use the **Timeline focus** variant.
- `weekly-review-layouts.html`: use the **Table first** variant.
- `weekly-review-week-states.html`: inspect all three state variants.
- `weekly-review-rearrange.html`: inspect **Default view** and **Rearrange mode**.

The HTML references communicate spatial hierarchy and interaction intent. Accessible production font sizing and explicit precedence notes in `../IMPLEMENTATION_SPEC.md` override literal mockup measurements.
